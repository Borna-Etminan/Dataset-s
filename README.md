## ✈️ [Twitter US Airline Sentiment (Clean & ML-Ready)](https://www.kaggle.com/datasets/bornaetminan/twitter-us-airline-sentiment-clean-and-ml-ready)
Cleaned version of airline-related tweets labeled with sentiment (negative, neutral, positive).  
Includes a **clean dataset for analysis** and an **ML-ready version with numeric labels and text features**.
- Approximate number of lines: 42,000

---

## 🛒 [Amazon Fine Food Reviews (Cleaned & ML-Ready)](https://www.kaggle.com/datasets/bornaetminan/amazon-fine-reviews-cleaned-ml-ready)
A processed version of Amazon food reviews with cleaned text and sentiment labels.  
Designed for **sentiment analysis, text classification, and NLP benchmarking**.
- Approximate number of lines: 1,200,000

---

## 📰 [Real vs Fake News Dataset (Cleaned – English)](https://www.kaggle.com/datasets/bornaetminan/cleaned-real-and-fake-news-dataset-english)
A cleaned English news dataset for **fake news detection** tasks.  
Text normalization and duplicate removal make it suitable for **robust ML and DL experiments**.
- Approximate number of lines: 77,000

---

## 🗂️ [News Category Classification Dataset](https://www.kaggle.com/datasets/bornaetminan/news-category-classification-dataset)
News headlines and short descriptions categorized into multiple topics.  
Prepared for **multi-class text classification and topic modeling**.
- Approximate number of lines: 400,000

---

## 💬 [Reddit Comments Sentiment Dataset](https://www.kaggle.com/datasets/bornaetminan/reddit-comments-sentiment-dataset)
Large-scale Reddit-style comment dataset labeled with sentiment.  
Includes **clean text, engineered features**, and an ML-ready format for fast experimentation.
- Approximate number of lines: 6,130,000

---

## 🎬 [IMDB Movie Reviews (Clean & ML-Ready)](https://www.kaggle.com/datasets/bornaetminan/imdb-movie-reviews-clean-and-ml-ready)
Cleaned IMDB movie reviews with binary sentiment labels.  
Widely used benchmark dataset prepared for **sentiment analysis and NLP models**.
- Approximate number of lines: 100,000

---

## 🍔 [Yelp Reviews Polarity (Cleaned)](https://www.kaggle.com/datasets/bornaetminan/yelp-reviews-polarity-cleaned-dataset)
Merged and cleaned Yelp review polarity dataset (positive vs negative).  
Optimized for **sentiment classification and traditional ML pipelines**.
- Approximate number of lines: 2,400,000

---

## 🎥 [Netflix Movies & TV Shows (Cleaned & Feature-Engineered)](https://www.kaggle.com/datasets/bornaetminan/cleaned-netflix-movies-and-tv-shows-dataset)
Cleaned Netflix catalog with engineered features such as **genres, durations, decades, and date features**.  
Suitable for **EDA, recommendation systems, and content analysis**.
- Approximate number of lines: 8,810

---

## 😄 [Emotion Text Dataset (Clean & ML-Ready)](https://www.kaggle.com/datasets/bornaetminan/emotion-text-dataset-clean-and-ml-ready)
Text-based emotion classification dataset merged from train/validation/test splits.  
Provides both a **human-readable clean version** and an **ML-ready dataset with encoded labels**.
- Approximate number of lines: 80,000

---

## 💳 [Credit Card Fraud Detection Dataset](https://www.kaggle.com/datasets/bornaetminan/credit-card-fraud-detectioncleaned-and-ml-ready)
A highly imbalanced financial transactions dataset designed for fraud detection research and machine learning modeling.  
Includes PCA-transformed features (`V1–V28`), transaction time, amount, and binary fraud label.
- Approximate number of lines: 1,135,000

## ✅ Key Features Across All Datasets

- Duplicate and noise removal
- ML-ready numeric labels
- Feature engineering (lengths, counts, dates where applicable)
- CSV and database-friendly formats
